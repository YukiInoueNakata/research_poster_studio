# Support / サポート

Need help with Research Poster Studio? Here is where to go.
*Research Poster Studio の使い方やトラブルの相談先です。*

## Documentation / ドキュメント

- [README](./README.md) — install, quick start, CLI, repository layout.
- `docs/` — `design.md`, `architecture.md`, `export-matrix.md` (export fidelity),
  `agent-workflow.md`, and `acceptance-tests.md` (manual GUI checks).
- `examples/` — runnable sample poster projects (input `poster.yaml` + content +
  figures, and rendered output in `exports/`).

## Questions & help / 質問・相談

- **Usage questions / 使い方の質問**: open a [GitHub Issue](../../issues) using the
  *question* link, or email the author.
- **Bug reports / 不具合**: open an issue with the **Bug report** template
  (include OS, version, and steps to reproduce).
- **Feature requests / 機能要望**: open an issue with the **Feature request**
  template.

## Contact / 連絡先

- GitHub Issues: <../../issues> (preferred for anything reproducible)
- Email: dj.y.nakata@gmail.com

Please do **not** report security issues in public issues — email the author
directly.
*セキュリティに関わる問題は公開 Issue ではなくメールでご連絡ください。*
